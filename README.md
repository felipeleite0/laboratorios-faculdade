# Laboratórios de Faculdade

Repositório com laboratórios, exercícios e exemplos desenvolvidos durante a faculdade, registrando minha evolução nos fundamentos de programação.

O conteúdo é educacional e mostra práticas introdutórias em Python, JavaScript e TypeScript.

## Conteúdos

- Listas em Python.
- Programação orientada a objetos em Python.
- Variáveis, tipos e execução de exemplos em TypeScript.
- Diferenças básicas entre JavaScript e TypeScript.
- Organização de exercícios para consulta e continuidade dos estudos.

## Tecnologias

- Python
- JavaScript
- TypeScript
- Node.js

## Como executar

No Windows, use:

```text
executar-exemplos.bat
```

Para executar manualmente os exemplos em Python:

```bash
python python/listas/lista.py
python python/poo/aluno.py
python python/poo/cachorro.py
```

Para executar os exemplos em TypeScript:

```bash
cd typescript
npm install
npm run verificar
npm run soma
npm run variaveis
npm run javascript
```
